# dataraflow-week15-supervised-learning
This repository contains my week 15 solutions covering Polynomial Regression, Multiple Linear Regression, Support Vector Machines, and Decision Trees completed under the DataraFlow Training Program.

The focus of this week is on core supervised machine learning techniques, with hands-on implementations, model evaluation, and interpretation.

## Topics Covered

The repository includes well-documented solutions for the following models:

### 1. Multiple Linear Regression

- Model formulation and assumptions

- Feature selection and interpretation

### 2. Polynomial Regression

- Capturing non-linear relationships

- Bias–variance considerations

### 3. Support Vector Machine (SVM)

- Linear and non-linear classification

- Kernel intuition and margin optimization

### 4. Decision Tree

- Tree-based learning principles

- Model interpretability and splitting criteria

## Tools & Libraries

The implementations primarily use:

- Python

- NumPy

- Pandas

- Matplotlib / Seaborn

- Scikit-learn

All experiments follow best practices such as:

- Train-test splitting

- Feature scaling where required

- Appropriate evaluation metrics

## Learning Objectives

By completing this week’s work, the objectives were to:

- Understand the mathematical intuition behind supervised learning models

- Apply regression and classification techniques to real datasets

- Evaluate model performance reliably

- Compare linear, non-linear, and tree-based approaches

- Build clean, reproducible machine learning workflows
